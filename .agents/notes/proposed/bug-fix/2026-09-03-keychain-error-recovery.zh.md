# Agent Note: 凭据暂不可读时保留并恢复原凭据

Status: proposed

[English](2026-09-03-keychain-error-recovery.md) | 中文

## Problem

ad-hoc 签名身份变化后，原生候选包把模型密钥显示为未配置，并把账号显示为已退出。加密凭据文件及其引用和私有权限均未改变。凭据提供器把钥匙串暂时不可用吞成了缺失状态，导致重试入口被隐藏，消费方也无法显示可操作的错误。连续读取多个引用还可能分别等待原生授权超时。连接器查询凭据状态失败时也不会发布对应连接器的错误。

9 月 4 日真实到点任务进入原有会话并结束，但请求准入时的凭据读取绕过了账号错误转换，最终显示英文原文和 `UNKNOWN`。密码或设备标识读取失败还会错误清除界面上的已保存密码状态。

9 月 5 日原生模型已成功响应，外壳仍显示启动时的钥匙串错误。恢复监听器在客户端 Context 上订阅了仅由 Host 发出的 `session/event`，导致恢复和模型运行错误都不能到达。

## Proposal

通过既有凭据 API 传递用户引用的暂时读取失败，并保留浏览器恢复 cookie 的独立处理。同一事件循环轮次只共享一次暂时失败，使启动批次不会重复等待；之后的用户主动重试会重新读取原生凭据库。模型错误在适配器激活前仍可见；模型和账号提供无需填写新内容的重试；连接器凭据错误只影响自身卡片。不得删除已存密钥、推断授权结果或绕过原生同意。

打包后的 macOS 客户端使用签名字节和钥匙串服务在各版本间保持一致的固定原生 broker。broker 只接受同一 App 包内签名有效的产品主程序请求，密钥只经过进程管道。首次升级由一个共享任务顺序解密完整旧 `safeStorage` 快照，通过 broker 写入全部条目，并记录已迁移或已删除的引用；并发消费方的状态更新也会串行落盘。授权失败时保留旧密文并允许用户主动重试。已记录为迁移的引用在钥匙串条目缺失时不得回退旧密文。显式删除先提交逻辑删除，再清理 broker，成功后清理旧密文，避免部分失败或回滚后复活。

启动目录探测失败后，模型可能恢复访问。每轮首次真实响应只对仍有 `GC-MODEL-KEYCHAIN` 的对应提供方复查一次。结果由既有 Host 探测决定；模型响应本身不能证明目录就绪。该操作按事件触发，不定期重试，不改变已选提供方或密钥。

消费当前选中 SessionBinding 事件源的实时增量，用请求头或模型响应确定提供方。切换会话时释放订阅，忽略历史替换和前插。不得新增 Host 事件流或通过类型断言订阅未转发事件。

## Alternatives considered

**把密钥报告为不存在。** 这样可以继续启动，却会给出错误的恢复指引，并隐藏已存密钥的重试操作。

**让应用激活等待钥匙串。** 系统提示会阻塞整个桌面组合。现有消费方已经支持后台恢复，可以在不阻塞窗口的情况下显示错误。

**清空凭据或永久缓存失败。** 清空会破坏有效的已存状态。永久缓存会阻止用户授权后的恢复。固定时长冷却也会引入与用户操作无关的重试延迟。

**跨版本只保留旧 `safeStorage` 文件。** 密文字节完全相同不能证明采用新 ad-hoc 签名的应用仍能解密。推迟目标包授权不能作为更新验收通过。

## Acceptance criteria

真实 Loader 组合在原生凭据库不可用时仍能挂载，显示受控的模型与账号错误，并在访问恢复后重用原模型密钥和账号 token，且不写入或删除凭据。提供器测试覆盖真实缺失、暂时拒绝、同轮合并、后续恢复、损坏存储和浏览器 cookie 行为。账号主动刷新遇到凭据错误时返回离线快照，不得因请求拒绝而永久停在检查中。账号与 MCP 消费方保留各自恢复状态。界面测试会在密码和密钥输入框保持为空时触发重试，覆盖检查中快照叠加传输错误，并在加载时禁用重复刷新。新签名原生包在发布前仍须完成真实授权、账号恢复和模型调用。

请求准入中的 token、用户名、密码和设备标识读取必须保留结构化 `GC-ACCOUNT-KEYCHAIN` 错误。账号快照保留已知用户名和已保存密码状态，不发出被拒绝的模型请求，并允许后续请求在不重写凭据的情况下恢复。重建后的原生包必须验证轮次错误的实际显示，不能仅用源码测试关闭到点任务的发现。

跨版本验收必须让准确目标包界面投影保留的账号和模型状态，确认每条合成引用均已迁移，并通过固定 broker 逐项读回完全相同的值。只有密文保留的结果判定失败。第二个有效 App 签名必须在不重新输入密码、也不再次执行旧存储迁移的情况下读取已经迁移的 broker 条目。

## Risks

首次旧存储迁移仍可能要求原生授权，因为旧 `safeStorage` 项目属于此前 App 身份。模拟凭据库拒绝的测试只能验证软件行为，不能证明 macOS 已授权或生产模型服务健康。迁移成功前，之后事件循环轮次中的读取仍可再次尝试原生访问；该机制不是永久关闭提示。
