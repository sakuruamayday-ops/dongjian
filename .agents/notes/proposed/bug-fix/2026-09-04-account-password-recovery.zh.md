# Agent Note: 客户端密码找回入口

Status: proposed

[English](2026-09-04-account-password-recovery.md) | 中文

## Problem

用户忘记密码时，账号登录窗口没有找回入口。网站与桌面客户端共用账号，另做桌面找回流程会重复维护账号规则。

## Proposal

候选改动在现有登录表单加入本地化的“忘记密码”链接。目标地址由 Host 已验证的门户地址决定；地址为空时隐藏入口。打开链接既不提交登录，也不传输表单内的账号或密码。公司名称匹配、密码替换和登录会话注销由网站负责。

这是新增找回入口，不替代启动时凭据恢复或现有钥匙串重试规则。相关决策记录继续有效。

## Alternatives considered

原生重置表单会重复网站的验证和生命周期。写死公开地址会忽略 Host 的账号配置。这两种方案均未采用。

## Acceptance criteria

产品侧栏测试共56项通过，覆盖未连接、离线及异地登录状态的找回入口、原登录输入保留，以及门户地址尚未加载的情形。转为 implemented 前仍需正式客户端制品及原生外部浏览器验证。本改动不替换 B18／B19 安装。

## Risks

主人明确选择账号加登记公司全称，未采用管理员核验或私有恢复码。公司名称属于公开信息，不能证明账号归属。网站保留限流和 CSRF 校验，但这些措施不能消除账号接管风险。本客户端候选不是正式安装包发布。
