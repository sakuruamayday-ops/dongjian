# Agent Note: 专业任务的用户选择会结束当前轮次

Status: implemented

[English](2026-08-31-professional-user-choice-stop.md) | 中文

## Problem

专业技能可能要求用户在检索或生成文件前选择报告模式。普通助手提问不持有轮次生命周期：专业完成门禁看到回执缺失后，会让同一轮继续执行，后续工作因而可能在没有用户回答时继续。最终文件校验虽能拒绝错误产物，却只能在检索和文档生成已经消耗时间之后发现问题。

## Decision

共创策略门禁把尚未确定的企业全景报告模式记录为 Host 状态。该状态解除前，只允许激活技能和调用 `ask_user_question`；检索、证据收集、校验和文件生成都会被拒绝。结构化提问成功返回 A、B 或 C 后才解除状态。若助手在最终正文中完整呈现 A/B/C 选项，轮次结束逻辑会把控制权交还用户，不再向同一轮追加纠正消息。

正式 Office 交付还会在生成 DOCX、XLSX 或 PPTX 前，使用当前已签名的 `deliveryProfileId` 对完整聊天候选执行结构预校验；生成后仍由文件模式重新打开并校验真实文件。前置检查会在缺少必需章节、表格、字段或顺序时阻止近似版式进入高成本生成路径。

## Alternatives considered

**把第一种报告模式作为默认值。** 已拒绝，因为报告模式会改变范围、证据深度、结构和成本，属于用户决定，不是部署默认值。

**只依赖最终文件校验。** 已拒绝，因为它会在检索和文件生成后才发现结构错误，既浪费任务时间，也没有取得用户选择。

**识别普通提问但不限制工具。** 已拒绝，因为同一轮中的后续模型步骤仍可能绕过尚未完成的选择。

## Consequences

企业全景任务会在联网发现前暂停并等待用户回答，不再从选项顺序或推荐文字推断模式。结构化提问是主路径，完整的普通 A/B/C 提问仍可作为安全轮次边界。正式 Office 生成增加一次本地确定性预校验，同时保留已有的真实文件校验和证据要求。
