# Agent Note：桌面企业空间、删除与拖动修正

状态：已实现

[English](2026-08-26-desktop-workspace-delete-and-drag.md) | 中文

## 问题

企业空间根目录选择器会拒绝有效的 macOS 文件提供方目录别名，并把设置写入、目录无效和访问权限问题都归为同一条笼统提示。删除对话后，产品列表只过滤归档标记而没有过滤删除标记，因此对话仍然可见；设置页又把删除展示成另一种可恢复归档。空白对话首页隐藏普通标题栏后，顶部白色区域没有可拖动窗口的命中面。

## 决策

企业空间根目录先解析为规范目录，再执行安装位置和宽目录检查。保存选择前验证目录可读写；产品错误投影分别识别设置写入、目录无效和权限失败，同时不暴露本机路径。

归档和删除继续作为两个独立动作。归档企业空间和归档对话保留恢复入口，也提供直接删除操作。删除企业空间和删除对话保留持久标记，防止陈旧 Host 扫描把它们重新加入列表，但全部产品列表和归档设置都不再展示或恢复。这只改变客户端可见性，不删除企业目录、生成文件或会话日志。

对话根节点为 macOS 空白首页提供 44 像素高的拖动区域。活动会话的普通标题栏保持在其上方，模型控件明确排除在拖动区域之外。

## 已考虑的替代方案

**拒绝所有目录别名。** 不采用，因为文件提供方和用户选择的 macOS 文件夹可以合法经过符号链接；安全策略应检查规范目标。

**继续从已归档页面恢复删除对话。** 不采用，因为这会与归档功能重复，并违背用户明确选择的删除命令。

**让整张空白页都可拖动。** 不采用，因为这会拦截输入框、模型和文件操作。

## 影响

合法重定向目录可以使用，访问失败会给出明确处理方向，删除会立即从企业空间和会话列表消失且不变成归档，macOS 顶部白色区域可以拖动窗口。持久删除标记只作为防止记录被重新扫描出来的存储机制，不再是用户可见归档。
