# Agent Note: 必须升级前先提交账号凭据

Status: implemented

[English](2026-08-29-account-credential-commit-before-required-upgrade.md) | 中文

## 问题

账号服务器可以在验证密码登录成功的同时要求使用更新客户端。如果在保存已验证 token 之前因兼容状态返回，新安装的应用仍会再次询问密码，尽管同一份服务器回执已经准入该设备。

## 决策

密码登录先校验登录回执及其设备绑定的 `/v1/me` 响应，再通过操作系统凭据服务提交账号、可选密码、自动登录标记和 token。只有完整成功路径结束后才发布 `connected` 或 `upgrade-required`。必须升级状态仍会拒绝代理请求，直到受支持的二进制验证保留的 token。

## 考虑过的替代方案

**不为不受支持的客户端保存任何材料。** 不采用，因为身份验证已经成功，并且签名应用更新需要该 token 才能保留登录状态。

**在更新开始前发布 `connected`。** 不采用，因为这会弱化服务器的最低版本决定，并允许不受支持的客户端继续执行模型任务。

## 影响

应用更新后可以恢复已验证账号，无需再次询问密码。被拒绝或回执不一致的登录仍不提交任何凭据，必须升级仍是模型请求的硬阻断。账号测试会使用已提交的凭据记录重建服务，同时证明恢复和持续阻断。
