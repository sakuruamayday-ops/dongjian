# Agent Note: 精确到模型的目录价台账

Status: implemented

[English](2026-08-14-model-cost-estimate-ledger.md) | 中文

## 问题

会话界面需要以紧凑方式反馈会话花费和今日花费，但不能把客户端估算冒充成提供方账单。不同提供方返回的用量结构不一致，自定义路由可能没有可信价格元数据，零值既可能代表真正免费，也可能代表缺少价格信息；如果只在渲染层计数，已结算用量更新替换前一个流式片段时还会丢失替换语义。

## 决策

**用量携带可选估算值。** 只有适配器知道适用目录价时，`TokenUsage.estimatedCostUsd` 才存在。数值零表示模型已知免费；字段缺失表示请求尚未计价，不能显示为免费。

**DeepSeek 适配器按请求时点为精确的官方模型标识计价。** 适配器持有[当前官方美元每百万 token 费率表](https://api-docs.deepseek.com/quick_start/pricing/)，覆盖 `deepseek-v4-flash`、`deepseek-v4-pro` 与 `deepseek-v4-flash-vision-exp`，并区分缓存命中、缓存未命中和输出费率。UTC 周一至周五 01:00-04:00 与 06:00-10:00 使用高峰费率，其余时点使用闲时费率。每次实际 chat fetch 都单独固定计价时点并用于整条响应，包括陈旧文件恢复后的新请求。只有提示、补全和缓存命中数量均为安全非负整数，且缓存命中不超过提示 token 时才提供估算。未知模型或别名保持未计价，不会因为名称相似而继承费率。

**pi-ai 适配器只信任已安装目录元数据。** 经目录解析的模型标识可以使用已安装模型目录返回的 cost total。手工声明的自定义路由，以及目录中不存在的标识，即使名称看似熟悉也保持未计价。

**token-meter 持有可持久回放的花费聚合。** `modelCost` 投影会用同一会话、轮次和步骤的新用量观测替换旧值，不会把流式更新重复累计。它分别记录已计价与未计价请求数量，按会话聚合，并依据宿主本地自然日汇总所有已列出会话。

**紧凑统计行保守呈现估算。** 它显示会话与本地当日估算；总量同时包含未计价请求时追加 `+`；完全没有已计价值时显示明确的未计价提示。模型名称和推理强度不进入这条单行统计。

## 曾考虑的替代方案

**按模型名称片段推断价格。** 不采用，因为别名和第三方路由可以复用熟悉名称，但实际计费不同。

**把所有零值统一当作未知或免费。** 不采用，因为两种语义都必须保留。字段可选性表示价格未知，数值零表示已知免费。

**依赖提供方账单或账户接口。** 不采用，因为自带密钥与订阅提供方没有统一计费 API，部分集成也完全不提供账户余额。

**把台账只放在渲染层 local storage。** 不采用，因为该投影需要 Host 回放、跨会话当日聚合，以及对重复已结算用量片段进行确定性替换。

## 后果

界面显示的是 API 目录价估算，不是账单、订阅余额，也不保证与提供方舍入口径一致。DeepSeek 的 UTC 费率表在官方页面变化时需要维护。自然日分组会依据当前宿主时区和已存时间戳重新计算。测试固定覆盖三个精确 DeepSeek 模型 id、请求时点高峰窗口边界与陈旧文件重试、缓存命中与未命中及输出计算、异常计数不计价、未知与免费语义、同一步骤替换、混合总量和单行界面文案。
