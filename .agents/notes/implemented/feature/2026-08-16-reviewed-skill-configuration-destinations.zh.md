# Agent Note: 经审查的技能配置地址

Status: implemented

[English](2026-08-16-reviewed-skill-configuration-destinations.md) | 中文

## Problem

社区市场可以标注某个技能依赖服务或凭据，但技能详情页未必是厂商的登录、授权或密钥管理入口。把市场详情地址直接当作配置地址，会使“安装并配置”跳到错误页面，也可能让用户误以为技能安装已经完成外部服务配置。

## Decision

魔搭与 SkillHub 的详情地址只用于来源追溯。社区技能只有在 Host 按精确技能坐标绑定经过审查的官方厂商地址时，才会在安装后自动进入配置。平台元数据仍可设置 `requiresConfiguration`；没有可信地址时，客户端标为“需要手动配置”，正常安装且不自动跳转。

自定义仓库清单可以携带公开 HTTPS `configurationUrl`，因为该地址属于仓库作者明确提供并经过清单校验的数据契约。已经安装的魔搭与 SkillHub 技能不再信任旧注册表中保存的配置地址，而是按当前审查映射重新投影，从而自动修正早期把社区详情页误存为配置页的记录。

## Alternatives considered

**把目录详情页作为配置地址。** 目录页面用于记录来源，却不一定提供厂商登录、授权或密钥管理；自动跳转到该页面可能把外部配置误示为已经完成。

## Consequences

技能卡片和详情明确区分三种状态：无需额外配置、需要手动配置但没有可信跳转地址、安装后进入经过审查的官方配置地址。已安装技能存在经过审查的地址时，详情会保留“打开官方配置”入口，方便以后重新配置。安装与配置继续是两个独立状态；打开厂商页面绝不会把外部工具标记为已就绪。后续新增自动跳转地址必须按技能坐标单独审查并补充回归测试。
