# Agent Note: 共创聚焦式侧栏与桌面设置

Status: implemented

[English](2026-08-15-gongchuang-focused-sidebar-and-desktop-settings.md) | 中文

## Problem

共创企业助手固定使用一套专业 Agent 组合，并在政策检索、同行查找、企业体检和报告流程中按需调用联网检索。第二个新建任务按钮、独立检索页面、两处常驻策略状态提示和只有一个选项的 Agent 预设选择器占用了本可用于显示企业最近会话的侧栏空间，却没有提供不同的用户操作。继承自 DSH 的设置入口也与产品侧栏视觉不一致，且没有桌面用户所需的原生更新和个人资料操作。

## Decision

产品侧栏只保留一个“新对话”操作。用户选择后进入助手并在当前工作区启动新会话。企业空间、技能中心、MCP 连接和自动化任务继续作为一级入口；联网检索不再拥有路由或独立页面。业务任务需要证据检索时，专业技能和签名宿主继续调用 `web_search`、`web_fetch` 与共创检索连接器。

签名宿主要求 `gongchuang` Agent 预设是唯一受系统信任的组合，并禁用 `ui-agent-preset`。该预设仍决定每个会话的提示词、工具、技能和校验插件，但用户不能选择、复制、编辑或绕过它。策略与技能校验也继续强制执行，不再显示常驻状态卡：签名无效时应用启动失败，专业校验或交付回执缺失时则在对应任务中阻断并显示可操作错误。

账号区下方提供产品自有的个人资料和设置入口，主侧栏不再重复显示客户端或技能包版本。个人资料接受不超过 5 MB 的 JPEG、PNG 或 WebP 图片，解码后居中裁切为 256 像素 WebP，只持久化该本机数据 URL。只有服务器会话处于 `connected` 时才显示已保存头像和账号名称；登录过期、被其他设备顶下线、验证中或未登录状态统一显示通用未登录图标。退出账号前必须明确确认：服务器同步、技能同步与 MCP 目录同步会停止，但企业目录、对话和已生成文件仍保留在本机。

设置采用紧凑的产品自有行式布局，并且只展示有真实服务支撑的操作。常规页不再重复首次安装时的模型选择、只有一个选项的专业预设或桌面运行时开关。标题栏关闭是固定产品行为而非用户偏好：关闭时隐藏主窗口并保留桌面运行时，直到用户在菜单栏图标菜单中选择“退出应用”；点击菜单栏图标会恢复并聚焦窗口。该行为不阻止系统休眠，客户端也不配置 Electron `powerSaveBlocker`。客户端更新与技能包更新继续独立展示。桌面包、宿主窗口、签名产品策略和便携运行时共用客户端语义版本，随附技能包版本独立演进。产品策略继续固定客户端与随包技能基线，专业合同和签名操作则绑定到 Host 完成 Ed25519 与逐文件校验后为本次启动选中的准确技能版本。因此，独立技能更新不会只因版本高于随包基线而启动失败；未签名技能包、版本不一致的操作清单或变化文件仍会在主窗口出现前失败关闭。更新器显示 `app.getVersion()`，渲染器桥不可用时显示未知或读取中，不再硬编码版本号。桌面打包先生成平台产物，再生成确定性元数据：macOS 发布[服务器自管 Ed25519 清单与分离式签名](2026-08-20-gongchuang-self-managed-macos-updates.zh.md)，Windows 继续使用 `latest.yml`；缺少元数据属于更新错误，不能据此显示客户端已是最新版。

侧栏品牌区优先完整显示“共创企业助手”，地区选择下沉为紧凑第二行，不再与产品名称争抢宽度。最近对话没有企业空间时明确显示“无”，企业空间没有最近对话时也显示“无”而不是数字零。当前对话采用 WorkBuddy 风格的一层浅灰圆角底色并覆盖完整行；每条对话采用单行布局，左侧显示标题，右侧时间无独立边框或方框。键盘焦点仍保留一像素低对比度轮廓。对话动作默认隐藏，鼠标悬停或键盘聚焦时用共享图标与提示组件承载的“更多”“归档”“固定”替换右侧时间。输入框的模型控件只保留无边框文字与下拉箭头，鼠标悬停和键盘焦点使用低对比度底色反馈，不再围住当前模型绘制框体。

最近对话中的企业空间和空间内对话保留 Host 顺序，并通过已有的 insert-before 操作支持指针直接排序。行项目始终使用普通箭头光标，不显示拖动把手、抓取手形光标或浏览器原生拖影。主鼠标键按住 180 毫秒后捕获当前指针并开始直接移动；短按仍执行原有的打开或展开操作。产品自有的紧凑拖影跟随指针并显示企业空间或对话标题，源位置显示为弱化占位，目标位置使用两像素插入线或企业空间内描边。拖影只用于视觉反馈，不接收指针事件，并限制在视口内，保证窄窗口中的完整拖动路径不会产生横向溢出。连续经过同一个落点时复用现有状态，不重复触发列表重绘。把对话释放到其他企业空间时使用已有移动操作。搜索状态禁用排序，运行中的对话不能发起拖动。渲染器不会预先修改列表顺序；操作失败时显示脱敏后的产品错误，并保持 Host 投影不变。固定和取消固定使用持久化企业空间服务；固定对话显示在前，固定组和普通组内部都保留 `sessionIds` 顺序。

企业最近对话提供可用键盘操作的右键菜单，可打开、复制、重命名、归档和删除。“复制”和“移动到企业空间”都会在鼠标移入时直接展开子菜单，键盘仍使用右方向键进入，移入其他一级操作时会收起已展开的子菜单。移动操作只保留一个“移动到企业空间”入口；筛选后没有可用目标时，子菜单显示可访问且不可点击的“无”空态。原先重复的“项目”行和独立移动对话框已经移除。企业空间行同样支持鼠标右键与键盘菜单键，可编辑企业名称、归档和移除。企业空间详情对会话和空间同样区分归档与删除。两类操作都只改变客户端登记状态，不会删除企业目录、已生成文件或会话日志。设置页只列出已归档企业空间和已归档对话；每个归档项都可以恢复或直接删除，删除后从全部产品列表消失，产品不提供恢复入口。

新对话的企业空间选择保留搜索与已有企业选择，但共创组合会把通用目录添加行替换为“新建企业”。该入口只关闭选择菜单，并在当前新对话上方打开同一套企业名称对话框，不会跳转企业空间页、不新建第二套选择状态，也不会静默连接任意目录。创建成功后通过已有企业空间操作连接并打开该企业的新会话；“不在企业空间工作”仍作为明确的无企业空间路径保留。

首次使用对话框同时完成必选城市和企业空间根目录设置。桌面 Host 准备 `Documents/共创企业空间`，要求用户进入前明确确认，也允许通过系统选择器改用其他已有目录。新建企业只接受一个可跨平台使用的目录名称，并在当前根目录下创建直属子目录；导入操作则原位连接已有的具体企业目录。设置只改变以后新建企业使用的根目录，不移动已连接空间。沙箱化预加载仅暴露这些有类型的操作，主进程会拒绝当前产品窗口之外的渲染器请求。

会话输入框左侧提供桌面原生“文件”操作。主进程只接受用户在系统对话框中明确选择的 DOCX、XLSX、PPTX、PDF 和 TXT，把普通文件复制到当前具体企业空间的 `共创导入资料` 目录，并向渲染器返回脱敏相对路径回执。源路径、任意目录扫描和源文件字节不会进入渲染器。随后由当前已签名技能包中的操作提取文档正文；文本 PDF 与扫描 PDF 状态严格区分，扫描件必须经已配置 OCR 成功后才能作为事实输入。

## Alternatives considered

**为两个新建任务入口保留不同文案。** 不采用，因为两者创建的是同一工作区会话，只会迫使用户在相同操作之间选择。

**把独立检索页面作为高级工具保留。** 不采用，因为证据检索应处于专业业务流程内；独立页面会鼓励脱离企业上下文的检索，并重复模型已经具备的 MCP 与技能编排。

**保留常驻绿色策略状态提示。** 不采用，因为签名策略不存在受支持的关闭状态。绿色提示占用空间却不能触发操作，真实校验失败必须在发生位置阻断。

**展示只有一个条目的 Agent 预设选择器。** 不采用，因为它暗示存在选择并暴露开发者编辑能力。同时也不删除宿主预设，因为产品依赖这套固定的专业组合。

**从设置中打开下载网站。** 不采用，因为网站跳转无法区分已是最新版、发现更新、下载完成和可安装状态。一次性 macOS 桥接安装完成后，这些状态由经过身份验证的客户端内更新器负责，服务器更新源仍属于部署配置。

**暴露窗口关闭或阻止休眠开关。** 不采用，因为关闭到菜单栏是产品默认行为而非用户偏好；阻止系统休眠与保持客户端运行无关，误启用还会浪费电量。菜单栏仍保留明确的退出路径。

**每次新建企业都复用通用工作区目录浏览器。** 不采用，因为普通新建只需要企业名称，并且必须在一个可见根目录下产生直属子目录。通用浏览器继续作为浏览器模式的回退方案，桌面端导入已有具体企业目录时使用系统目录选择器。

## Consequences

在相同窗口高度下，侧栏能够展示更多企业会话，每个可见的一级入口都有不同的产品操作。完整产品名称保持可读，企业空间空状态没有歧义，当前对话样式也不再压过内容。新对话可以进入已有企业空间、新建企业空间，或保持未分组而不改变已有企业登记。联网检索、策略执行和 Agent 组合的技术状态更少暴露，但仍是强制运行行为；只有用户能够处理异常时才显示诊断。

头像只保存在当前设备，不通过账号服务器同步。已保存头像可以在下次有效登录后继续使用，但绝不会代表已经失效的服务器会话。自动更新能力依赖已配置的平台更新源及其完整引用产物。macOS 上的已安装 Host 会先验证准确的服务器 JSON 与分离式签名，再选择对应架构压缩包；Windows 的 Electron 元数据通道保持独立。客户端发版不会改名或推进已安装技能包版本。产品外壳不再展示通用 DSH 设置页或 Agent 编辑页。

标题栏关闭不会退出客户端。用户通过菜单栏图标恢复窗口，并通过菜单栏“退出应用”主动停止运行时。该方式可以保留进行中的本地运行时工作，又不会申请系统级阻止休眠；操作系统重启或用户显式退出仍会终止进程。

导入文件的副本属于当前企业空间，可被同一企业后续会话复用，从而减少重复上传与重复提取；是否命中模型缓存仍取决于会话前缀，不能仅凭文件已导入保证。旧版 Office 文件、压缩包和批量文档目录扫描不属于 V0.1。

企业空间根目录只保存在当前设备，并与客户端安装目录分离。切换根目录不会迁移或删除客户文件；如果需要物理搬迁，用户应在客户端之外完成，再连接搬迁后的具体目录。
