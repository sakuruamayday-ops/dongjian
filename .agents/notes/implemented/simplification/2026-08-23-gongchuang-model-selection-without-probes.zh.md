# Agent Note: 共创无探针模型选择

Status: implemented

[English](2026-08-23-gongchuang-model-selection-without-probes.md) | 中文

## 问题

共创模型选择器把普通切换动作绑定到一次可能计费的一令牌对话探针，还会在打开选择器、网络恢复和连接事件后刷新可变的中转站目录。这些请求会消耗用户额度，让本地选择依赖外部服务状态，并展示对用户选择没有帮助的验证状态、同步时间和推断能力标签。中转站动态元数据还可能覆盖已安装的精确模型目录，导致推理强度控件消失。使用量条注册在没有渲染的输入 slot，中文界面也会原样展示上游返回的英文思考过程。

## 决策

Host 在客户端启动时为已配置提供方刷新一次模型目录。渲染器第一次读取快照时等待同一刷新承诺完成，因此快速挂载也不会在 Host 已经稳定后继续停留于瞬时 `checking` 投影；这不会发起第二次请求，也不会阻塞 Electron 主窗口。此后只有用户点击底部常驻的“刷新模型”命令才再次刷新目录。打开选择器只读取 Host 已稳定的快照；切换模型或推理强度只提交当前会话选择。两项操作都不刷新目录、不验证模型、不发送对话补全，也不改变其他会话。连接、设置、凭据、适配器和会话变化通知只更新可用性，并把当前会话的持久提供方投影到产品外壳，不会调用 `session.selectModel`。产品在绑定这项投影前声明 `ModelDirectoryResolver` 所需的嵌套会话 Remote；否则首个会话可能在该命名空间获得授权前到达解析器，并静默丢失首次订阅。只有用户明确选择、配置或重新检查提供方连接时才可提交路由，因此会话回放完成前短暂出现的 Host 默认值不会在重启时替换已保存模型。

产品移除逐模型验证 Remote、验证缓存、确认弹窗、技术验证状态、同步时间，以及文本、图片、推理或文件能力标签。所选模型能否使用由用户的正常对话请求证明；普通错误保持可见，用户可重试、刷新目录或切换模型。配置阶段的凭据鉴权与已鉴权 `/models` 发现仍由 `@gongchuang/model-connections` 负责，凭据继续保存在操作系统凭据库。

用户明确刷新时，各已配置提供方独立收敛。某个提供方失败会保留自身错误回执；只要另一个提供方返回已就绪或已明确登记的非空目录，本次刷新仍成功且该健康提供方继续可选。只有 Host 调用失败、无法读取替换目录，或没有任何已配置提供方返回可用目录时，选择器才清空全部行。

一次成功目录没有列出当前模型时，选择器可以如实提示，但不将其视为模型不可用的证明，不锁定输入框，也不强制用户先选替代项。私有、手填或尚未广告的模型可继续通过正常对话路径尝试；只有 Host 明确报告当前路由无可用适配器，或产品连接本身不可用时，才阻止发送。

按提供方分组的行只显示提供方名、模型名、选中标记和刷新命令。每个提供方标题可独立展开或折叠；进入模型层后焦点落到搜索框，搜索只按提供方或模型的名称与 ID 过滤内存目录，并在搜索期间临时展开命中项而不改变已保存的折叠状态。搜索、展开和折叠均不刷新目录或验证模型。已安装的精确模型目录声明推理强度时，推理强度继续作为独立控制。OpenCode Go 的已鉴权目录行继承已安装目录，不再保留过期的动态覆盖，因此 DeepSeek V4 Pro 会显示适配器支持的 `off`、`high` 和 `max`。

会话使用量条通过 `conversation.composer.dock` 注册到输入框下方。中文界面遇到英文占主导的思考文本时，仅在本地折叠成推理行已有的中文中性进度文案；中文或有实际意义的中英混合推理仍可查看。这一识别不调用翻译模型，也不额外消耗 token。

本决策部分替代[已验证模型连接](../architecture/2026-08-15-gongchuang-verified-model-connections.zh.md)中的选择探针和技术状态展示；其中凭据、目录发现、事务持久化、适配器采用和安全边界继续有效。

## 曾考虑的替代方案

**保留一令牌探针，只移除确认弹窗。**不采用，因为选择模型仍会消耗额度，本地偏好变更仍被变成一次外部请求。

**每次打开选择器或连接事件发生时刷新。**不采用，因为启动与明确刷新已经覆盖受支持的新鲜度时点，无需在普通选择时重复联网或引起目录抖动。

**每次后台连接事件都协调模型路由。**不采用，因为会话回放完成前可能短暂出现 Host 默认值。写入这个过渡值会再次触发设置刷新，并把错误路由持久化。

**再调用一个模型翻译英文思考。**不采用，因为翻译会增加延迟、token 成本和一次额外的思考内容披露。本地隐藏具有确定性，而且不影响正常回答。

**中文界面隐藏全部思考。**不采用，因为提供方返回的中文思考和含技术术语的中英混合思考仍有查看价值。

## 后果

模型搜索、提供方折叠和模型选择立即生效且不消耗额度，目录新鲜度则由启动和用户明确刷新控制。选择器不再声称当前交互没有证明的能力或验证确定性。所选模型第一次执行真实任务时仍可能失败；这是如实暴露服务状态，而不是用隐藏的预检请求代替。精确已安装目录重新拥有推理等级，使用量条进入实际渲染的输入框下方，英文占主导的思考也不再打断中文阅读。

定向测试固定启动加载一次、第一次快照随该次加载稳定、后台刷新没有模型写入权限、持久提供方投影、打开时不加载、每次明确点击只远程刷新一次、搜索框聚焦与本地过滤、提供方折叠、切换不验证、模型行保持简洁、OpenCode Go 推理等级恢复、使用量位于输入框下方，以及英文思考本地隐藏。打包验收会在重启前完成一次真实提供方回复，重启后要求提供方和模型经过稳定时间窗，再完成第二次真实回复，随后才把持久化记为通过。
