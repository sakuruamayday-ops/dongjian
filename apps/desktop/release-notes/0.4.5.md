# V0.4.5 更新说明

- 修复部分旧会话因显示文本、费用或历史响应格式差异而无法加载的问题，保留原始历史文件。
- 修复长回复底部看不到注释来源编号的问题；不同提交的同号注释可区分，编号保持中性灰色。
- 修复相似文件名被错误合并的问题；会话跨企业空间派生时保留已上传附件，遇到文件冲突明确提示。
- 修复归档空间中的会话通过链接或自动任务结果打开失败、导航错误不可见的问题。
- 修复自动任务把等待用户、待完善稿或失败误显示为完成的问题，不增加自动重试次数。
- 修复模型凭据读取失败后一直停在检查中的问题，保留已有密钥与推理选择。
- 内嵌 V1.6.19 技能套件，财税报告完整保留计算与来源条目，超过单页时自动续页。

本版继续使用 DeepSeek Harness 0.1.3-alpha.1。macOS 使用 ad-hoc 签名与更新包完整性验证，无 Developer ID 公证；Windows 安装程序暂无 Authenticode 签名。
