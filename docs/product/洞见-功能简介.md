# 洞见

面向项目申报、企业咨询和知识产权工作的桌面 AI 客户端。

把企业资料、项目对话、专业技能和生成文件放在一个工作空间里，减少在文件夹、网页和聊天窗口之间来回切换。

## 可以做什么

- 企业空间：按企业组织资料、项目对话和交付文件，让不同客户的工作保持独立。
- 资料阅读：导入文档和图片，围绕已有材料提问、整理信息、核对差异。
- 项目申报辅助：结合专业技能开展政策检索、项目匹配、申报材料撰写和一致性检查。
- 企业与知识产权分析：整理企业画像，辅助专利核稿、知识产权评估和财务指标复核。
- 文件交付：在对话中生成文档与表格，直接打开生成的文件继续编辑。
- 自动任务：设置定时任务，处理政策跟踪、资料检查等重复工作。任务需要客户端保持运行。
- 模型与 MCP：自行配置模型服务，通过 MCP 接入知识库、企业数据和 OCR 等外部能力。

## 使用方式

无需注册客户端账号。首次使用配置自己的模型服务；需要知识库时，再单独配置 MCP 地址与访问凭据。

企业资料、会话和偏好保存在本机。调用模型、MCP 或 OCR 时，相关任务内容会发送至用户选定的服务，不等于完全离线运行。

AI 输出需要复核；政策资格、财务数据和专利状态应以有效资料及权威来源为准。
