## 2. 背景、用户与问题

面向需要自行选择模型服务的项目申报从业者，提供企业资料整理、专业技能、对话、自动任务和文件交付。用户可直接打开客户端配置模型；专业知识库通过独立 MCP 凭据接入。

## 3. 产品定位与目标

独立桌面项目申报助手，沿用 V0.4.7 的界面和工作流程。无需产品账户即可使用本地功能，用户自行配置模型，新生成文件不含共创品牌与水印。交付范围包括 GitHub 仓库提交与功能简介；不包含新域名、生产网站或服务器变更。

## 4. 范围与用户体验

下载安装后进入本地工作区，完成模型配置即可使用。知识库在连接设置中单独填写 MCP 接入信息。企业空间、历史、附件、技能及自动任务沿用现有能力。产品名称为洞见，副标题暂不设置。

## 6. 产品与技术方案

使用独立 Git 工作树承载产品改造，复用 Electron、DSH profile 与现有产品插件。保持操作确认、文件访问限制、系统凭据保护和制品验签机制。产品账户限制按独立产品需求调整；知识服务访问仍由独立 MCP 凭据鉴权。

## 7. 交付与发布

0.1.0 为首个通用版测试候选，已交付[私有仓库](https://github.com/sakuruamayday-ops/dongjian)及 [Mac arm64 DMG/ZIP](https://github.com/sakuruamayday-ops/dongjian/releases/tag/v0.1.0)，附功能简介、使用边界和制品摘要。GitHub 回读确认发行非草稿、预发布，两项附件状态为 uploaded，字节数与 SHA-256 均与本地一致。仓库 Actions 已关闭。未发布至现有网站，未修改网站下载入口、共创版更新渠道或生产服务器。

## 8. 风险、依赖与开放问题

内置技能及运行时包含签名和产品标识，改造必须重新构建并签名，不能修改签名载荷后直接复用旧签名。独立更新渠道尚未发布；默认不连接原产品更新通道。知识库凭据由 MCP 服务提供方签发，不能自动复用旧产品的设备登录令牌。
