# @gongchuang/client-ui

[English](README.md) | 中文

## 概述

通过深链接或自动任务结果打开归档会话时，先恢复所属归档空间。桌面深链接等待会话和空间列表就绪，导航失败在侧栏显示。自动任务结算读取本轮交付分类：待用户处理、暂停、草稿和失败不会误记为完成，而是保留可处理的非成功结果；不新增自动重试。

Office、PDF 与 WPS 附件的模型上下文指明已安装文档读取入口及相对路径字符串参数，要求复用成功提取的正文并只补充缺失页 OCR，不启动企业首次配置或报告流程；TXT 与 Markdown 保持普通附件路径。

这是共创企业助手的私有浏览器产品外壳。它通过 Web Client slot 系统组合品牌侧栏和页面浮层；账号、模型提供方、连接器、技能市场、自动化、企业空间及会话状态仍由各自所属的 Host 服务或客户端运行时服务持有。

## 产品行为

Host 提供账号门户地址后，账号登录表单显示“忘记密码”链接。它在独立浏览器上下文打开 `/password/reset`，不会发送表单输入或提交登录。用户在网站填写登记的账号和公司全称，设置新密码后返回登录；门户地址尚未加载时不会生成指向本机的找回链接。

操作系统凭据库暂时不可读时，模型和账号窗口都提供直接重试。即使模型适配器尚未激活，模型错误仍保持可见；未知凭据状态不会因“已保存密钥”标志为空而隐藏重试。账号窗口会区分账号暂不可用和已确认退出；重试不会提交新的登录信息或 API Key。

模型恢复与运行失败提示消费当前选中会话的客户端事件流实时增量。受影响的提供方由模型响应及请求头确定，不依赖全局选择。切换会话会释放旧订阅；历史替换和翻页不会重新触发凭据探测或回放旧模型错误。

该外壳提供 DeepSeek、OpenCode 和自定义模型提供方选择，以及企业空间、已安装与市场技能分栏、带翻页的 ModelScope、腾讯 SkillHub 和自定义仓库搜索、MCP 配置、本地自动化、本机图记忆控制、个人头像和桌面更新控制。社区技能只有在 Host 提供经过审查的官方厂商配置地址时，才会在安装成功后自动进入配置；已安装技能详情会保留“打开官方配置”入口，方便以后重新配置。平台只标注“需要配置”但没有可信地址时，界面会提示手动配置，绝不会误跳社区详情页。联网检索没有独立页面，由专业任务按需使用 Host 已装载的检索工具。渲染器操作调用有类型的 Remote API，绝不接收密码、模型提供方密钥、连接器密钥、已下载 ZIP 字节、导入文档的源路径或字节，以及已存记忆正文。

会话输入框提供桌面原生文件选择器和文件拖入区。用户主动选择的任意普通文件都可复制到本次对话的私有导入目录，目录和符号链接会被拒绝。PNG、JPEG、WebP、GIF 拖入继续使用上游图片附件路径；混合拖入会拆分图片和文档，并复用常驻输入框的图片接收回调、数量限制和锁，不把图片复制成纯文本文档。渲染器只收到文件名、受控相对路径和大小，不接收源路径或文件字节。

导入文件保存在当前会话的独立附件状态中：输入框不会出现自动生成的说明文字或重复的成功提示，只有用户真正发送任务时才附带受控文件引用。浏览器持久化负责页面重载后的待发送引用恢复。桌面端还会把未发送文字、文档引用和编号注释保存在私有用户数据目录中，因此本地端口变化或应用更新不会改变它们的存储身份。原生恢复不会覆盖读取期间发生的用户编辑；损坏的持久化引用会在准备提示词之前被丢弃。发送失败保留文件卡。发送成功只消费本次已准备的快照，保留之后新导入或重新添加的引用；删除后的发送结算不能重建已经删除的草稿。点击文件卡会让桌面 Host 打开受控导入副本，关闭控件只从当前待发送消息中移除该引用；两项操作都不会暴露任意路径，也不会删除或移动文件。旧客户端写入草稿的附件说明会迁入同一状态。原生选择器会记住上一次仍有效的源目录。实际读取仍取决于格式能力：受支持的 Office 和文本文件使用已验签文档操作，扫描型 PDF 仍需先配置 OCR。

持久化浏览器存储只包含当前页面、已选模型提供方类别、账号对话框修订号和经过裁切压缩的本机头像数据。模型提供方选择会从当前 Host 目录解析可用模型；凭据或路由缺失时会显示明确错误，绝不会静默切换到另一类模型提供方。模型菜单在本地搜索并折叠提供方，打开菜单或选择模型都不验证提供方。桌面启动时，Host 模型连接服务完成唯一一次提供方刷新；此后通过用户点击“刷新模型”刷新。每轮首次真实模型回复也可对仍有 `GC-MODEL-KEYCHAIN` 错误的对应提供方复查一次，只有 Host 复查成功才清除该错误，且不改变已选路由；刷新收敛后选择器会强制重读全局模型目录。连接、设置、凭据、适配器和会话变化通知只更新可用性，并把当前会话的持久提供方映射到产品外壳，绝不会调用 `session.selectModel`；只有用户明确选择、配置或重新检查提供方连接时才可提交模型路由。产品会在绑定这项投影前声明嵌套的会话 Remote，首个会话不会与 Remote 命名空间激活产生竞争。会话恢复期间短暂出现的 Host 默认值因此可以被随后回放的持久选择替换，而不会被产品再次写成新默认值。单个提供方失败时，错误只保留在该提供方状态中，其他健康提供方继续可选。Host 调用整体失败、目录重读失败或刷新后没有任何已配置且可用的提供方时，才清空可选行并保留可重试错误，不把整个目录冒充为已刷新。账号客户端同样等待已收敛的 Host 刷新，不再停留在瞬时 `checking` 状态。已保存的账号、密码和 token 因此可从 macOS Keychain 或 Windows Credential Manager 恢复，且不会进入渲染器。登录表单默认勾选保存凭据与自动登录，用户仍可主动取消。账号已连接时，侧栏账号卡只显示本机头像和当前用户名；必须升级仍在非连接状态保留阻断详情。macOS 签名应用下载会显示百分比和剩余时间，把与校验器绑定的前缀保留到重启后，并提供明确的“继续更新”操作而不移除已保存账号材料。Windows 点击右上角关闭按钮时会打开紧凑的渲染器弹窗，以无框体的纵向单选项选择最小化到托盘或经正常运行时关闭流程直接退出；记住选择后才持久化，设置页用紧凑下拉框恢复“每次询问”。

最近对话严格保留 Host 顺序。主鼠标键按住 180 毫秒后解锁企业空间或对话行，普通箭头光标保持不变；进入拖动后显示紧凑单行拖影、淡化源位置，并标出准确插入边界或目标企业空间，不在客户端预改列表。右键菜单中的“复制”和“移动到企业空间”都会在鼠标移入时直接展开；键盘继续使用右方向键进入子菜单，移入其他一级操作时会收起子菜单。

“复制深链接”会生成产品自有的 `gongchuang://threads/<session-id>` 地址。安装后的桌面应用负责校验和接收该协议；本机已归档对话会先恢复再打开，已删除或未知对话会被拒绝。该地址只用于同一设备导航，不是公开分享链接。

粘贴图片草稿使用同一私有原生记录，恢复后进入常规图片发送注册表。图片标识未变时复用编码；销毁期间继续排空已捕获的写入值，删除会话后拒绝迟到的编码。既有草稿文件总计 4 MiB 的限制也包含图片字节。超限或保存失败时保留内存草稿并显示输入框错误，不静默宣称能够重启保留。文件引用不包含文档正文，此存储不接收凭据。

桌面图片传输授权在独立的私有用户数据文件中只保存用户明确同意的服务商标识，不依赖渲染器的本地端口。授权必须保存成功才会继续发送图片。读取或写入失败时保留草稿并显示可重试错误；保存期间取消或切换服务商不会放行待发送图片。纯浏览器客户端仍按页面来源保存授权。参见[原生授权决策](../../../.agents/notes/proposed/bug-fix/2026-09-04-native-image-consent.zh.md)。

“已归档”设置只展示已归档企业空间和对话，并为每项提供“恢复”与“删除”；任何已删除项及其恢复入口都不在这里显示。桌面删除只向 Electron Host 传递不透明的企业空间标识或会话标识。Host 从权威注册表和持久层解析路径，刷新并关闭自己持有的会话生命周期，等待持久写入器退休，再将企业目录或对话记录移入系统废纸篓或回收站。单个对话会先写入持久隐藏标记，移入回收站失败时恢复该标记；企业空间部分搬移失败时保留注册项供用户重试。删除成功后清除该对话尚未发送的附件草稿；仅关闭输入框文件卡绝不会删除已导入的企业文件。

需要凭据的 MCP 卡片会打开连接器专属配置向导。企查查优先提供“登录并授权”，由系统浏览器打开官方页面、授权后自动回到客户端完成连接，同时保留手动 API Key 备用入口。天眼查和 PaddleOCR 按各自官方令牌方式配置。只有 Host 核验凭据并发现至少一个工具，连接器才会变成已就绪；“我已完成配置”不会自行伪造成功。连接失败时页面和向导都会显示可选中的诊断，并提供“复制错误”按钮。PaddleOCR 向导会在授权前说明共创企业助手私有浏览器产品外壳使用百度 AI Studio 官方远程 API，要求用户明确确认数据传输，并区分连接验证与后续由用户主动发起的文件上传。

企查查和天眼查的浏览器授权不会占用全局设置队列。取消、Escape、关闭窗口和离开页面都会取消对应 Host 事务，覆盖注册、回调、令牌交换和凭据核验。晚到结果不能替换凭据，也不能关闭较新的窗口。既有凭据独立恢复，恢复未完成会报告错误。取消确认失败后仍可重试，天眼查短时轮询允许显式重试完成操作。其他连接器仍可用，旧快照不能覆盖较新的 Host 修订。

首次进入桌面客户端时，用户选择杭州、绍兴、金华、宁波或“全部”，并确认以系统“文稿/洞见企业空间”作为企业根目录，也可以选择其他已有目录。Host 将两项选择持久化在安装目录之外。新建企业只需输入名称，客户端会在当前根目录下准备同名直属子目录；导入已有企业目录时原位连接，不复制或搬动文件。设置页可切换以后新建企业使用的根目录，已连接空间不会被移动。市级和区县级内容按当前城市检索，浙江省级、国家级项目与通知四地市共享，名单类查询仍保持当前城市边界。任务中明确指定其他地区时，以任务要求为准。品牌区的城市按钮可随时重新打开选择器，切换后只重载知识连接器。选择器关闭时，草稿会跟随已经收敛的 Host 快照；保存时同时携带该快照作为预期旧值，避免启动占位值覆盖已恢复的选择。

当前会话正文使用上游 `ui-chat` 的 Turn Navigator。共创不再注册第二套轮次滑轨；历史恢复与前置加载、流式性能、键盘访问、预览和视口跟踪均由共享 Chat 实现负责。

选中的对话文字会保存为逐会话编号注释，与可编辑草稿彼此独立。数量入口可展开引文、可选评论和单项移除。删除后，待发送注释及其原消息标记从 1 连续编号；全部删除后，再添加从 1 开始。恢复的草稿使用同一编号规则。已发送历史与用户手写正文不改写。草稿会跨浏览器重载和发送失败保留。发送成功只消费已准备的快照，保留之后新增和修改；删除会话会同时清除注释和文档草稿。文档与注释通过 `conversation.input.payload` 展示在输入框内部，独占整行宽度，多项附件自动换行。文件卡继续调用既有系统应用打开器，不会创建对话。[决策记录](../../../.agents/notes/implemented/feature/2026-09-03-gongchuang-numbered-annotations.zh.md)。

<a id="dev-note"></a>
## 开发备注

该私有产品包负责注册品牌客户端 slot；账号、连接器、更新、企业空间和文件等安全敏感操作仍由上文指定的签名桌面 Host 服务负责。

## 运行时不变式

不发布运行时不变式伴随入口，因为已签名的 Host 组合会固定本包，而持久化视图存储与插槽生命周期由 Cordis 持有。

<a id="model-experience"></a>
## 模型体验

### 提供方配置

#### 模型看到的内容

配置界面不会把提供方凭据、连接错误或已存密钥状态写入模型消息。明确选择模型会改变下一次请求使用的 Host 路由。替换密钥探测失败时，Host 已知的凭据存在状态和使用已存密钥恢复的操作都会保留。快照重读失败或配置、刷新调用被拒绝时会显示明确错误，不会无限加载，也不会声称已存密钥消失。

#### Token 影响

配置和连接探测不会增加对话 token。

#### KV Cache 影响

配置不会增加提示词前缀。选中的提供方和模型使用该路由的缓存行为。

### 编号注释

#### 模型看到的内容

普通持久用户消息会携带编号引文、来源行标识、评论和当前用户正文，并用简短说明区分历史引文与新请求。独立的持久展示文本负责投影文件卡、注释数量和原正文，不新增 Session 事件或 RPC 方法。允许只发送注释。引文不是可信证据，也不构成授权。

#### Token 影响

选文与评论只在发送时增加输入 token。展开列表、修改评论、移除待发送条目和打开文件都不会发起模型请求。

#### KV Cache 影响

注释随下一条用户消息追加。已有对话内容和此前请求前缀保持不变。

### 本地图记忆控制

#### 模型看到的内容

设置页控制 Host 是否提取和召回本地记忆，以及工具结果能否参与提取。它不会发送聊天消息，也不会把记忆正文传给渲染器；模型可见的召回内容和工具由 `@gongchuang/graph-memory` 负责。

#### Token 影响

打开设置、读取汇总计数、修改开关或清空本地记忆都不直接增加 token。后续请求由记忆包按 Host 设置生效。

#### KV Cache 影响

这些控制不会改写会话。修改偏好或清空记忆可能改变后续的记忆上下文后缀，同时保留此前消息。

### 任务驱动的证据检索

#### 模型看到的内容

外壳不提供独立检索提交动作，也不会单独追加检索消息。专业技能和签名 Host 根据当前业务任务决定是否调用共创联网检索 MCP、`web_search` 与 `web_fetch`，并执行各自的来源和证据要求。

#### Token 影响

侧栏和 MCP 状态展示不增加 token。检索工具只在当前业务会话实际调用时产生模型输入和工具结果 token。

#### KV Cache 影响

检索结果留在发起它的企业会话中，并保留此前可复用的会话前缀；外壳不会为检索创建第二套独立会话。

### 本地自动化派发

#### 模型看到的内容

Host 发出到期或手动运行认领后，外壳会发送一条普通用户消息，其中包含本地任务名称、计划时间、签名策略提醒和已保存任务提示词；运行失败或未被认领时不会发送模型请求。提示被接收不等于任务成功：客户端会继续观察普通结果会话，直到出现完整助手回复或终止错误，再把“已完成”或“失败”及结果会话 ID 写入本机回执。创建或编辑任务时，用户既可以用“每天上午 9 点”“每周一上午 9 点”或“每隔 90 分钟”等中文描述填入可复核的时间设置，也可以手动选择首次执行时间、预设周期或 5 分钟至 365 天的自定义间隔。自然语言识别只填表，不会绕过最后的“保存并启用”操作。

#### Token 影响

每次派发会增加一段包装文字和已保存提示词。轮询和任务列表渲染不增加 token。

#### KV Cache 影响

自动化消息会追加到任务所属企业空间会话。更早历史保持前缀稳定；任务变更只影响未来追加的消息。

<a id="known-limitations-and-deferred-work"></a>
## 已知限制与延期工作

- 浏览器渲染不是安全边界；签名桌面 Host 必须验证 RPC 身份、固定本包，并强制执行模型提供方、工具、第三方和交付策略。
- 外壳依赖 Host 服务提供原生文件选择器、凭据存储、外部授权页面、安装和任务执行；服务缺失时会明确失败，不会回退到仅浏览器端的模拟功能。
- 文件导入接受普通文件，但绝不会扫描目录或跟随符号链接。文件复制到企业空间不等于已安装工具一定能解析其格式。
- 已排队的文件和注释消息会显示紧凑的文件名、数量和正文摘要。它们保留移除与补充指令能力，但不提供会丢弃附件上下文的纯文本编辑器。
- 记忆页只显示个人与企业汇总计数，并可清空全部本地图数据；共创企业助手私有浏览器产品外壳不提供图节点逐条编辑。
