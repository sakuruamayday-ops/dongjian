# @gongchuang/account

[English](README.md) | 中文

## 概述

共创企业助手 V0.1 由 Host 持有的账号密码登录服务。渲染器通过私有 Remote 方法提交字段；Host 携带稳定随机设备标识调用 HTTPS `/v1/client-login`，并用返回 token 请求 `/v1/me` 完成验证后才发布 `connected` 状态。

<a id="behavior"></a>
## 行为

账号、可选的已保存密码、token、设备标识和自动登录阻断状态只通过操作系统凭据服务保存。密码和 token 绝不进入客户端安全快照。启用“记住密码”后，启动时可以直接复用已保存凭据，无需把密码发送给渲染器。服务器已验证但标记为 `upgrade-required` 的登录会先提交与普通成功路径一致的账号材料，再发布必须升级的阻断状态，让更新后的应用无需再次输入密码就能恢复。服务器对同一账号只允许一台活跃设备：新设备登录会撤销前一个 token；被顶下线的客户端会阻止自动抢回登录，直到用户明确手动登录。主动退出会清除已保存账号、密码和 token，但保留稳定设备标识。

Host 激活不会等待凭据读取或服务器验证。服务先发布 `checking`，再在串行账号操作队列中后台刷新，因此 Web 服务和首个窗口可以继续启动。账号客户端首次加载会明确调用 `refresh`，串行队列会等待正在进行的 Host 恢复并返回稳定状态，不再把界面固定在瞬时 `checking` 快照。所有刷新入口，包括用户主动重试，都会把凭据读取被拒绝转成脱敏的 `offline` 快照。最近一次账号元数据和操作系统凭据保持不变；恢复时重新验证已保存 token，无需重新输入密码。

会终止模型请求的账号准入错误会以结构化 `LlmError` 穿过智能体循环。网络、未登录、升级、设备冲突和凭据读取路径因而保留各自的 `GC-ACCOUNT-*` 错误码，不会变成 `UNKNOWN`；原始原因只供 Host 诊断使用。凭据暂时不可读时保留已知用户名和已保存密码状态，供重试恢复。渲染器会在加载、窗口重新可见以及可见期间每六十秒刷新一次；每个模型请求仍会独立核验当前设备。

同一 Host 服务负责本机个性化。设置页和 `edit_personalization` 通过同一个串行原子写入器读写隔离 DSH 目录中的 `AGENTS.md`。仅缺失文件时初始化可编辑默认内容，已有自定义指令和明确留空的文件保持不变。快照返回当前正文、默认内容、更新时间和字符上限，不暴露文件路径。低优先级包装不能替换签名专业规则或产品安全约束。编辑器限制只拒绝无效保存，不阻断普通会话启动。

<a id="dev-note"></a>
## 开发备注

Host 通过操作系统凭据服务保存账号材料，并只向渲染器返回已脱敏的账号与个性化快照。

<a id="runtime-invariant"></a>
## 运行时不变式

不发布运行时不变式伴随入口，因为远程命名空间只暴露 Host 私有状态，凭据由凭据提供方提交，本包不持有独立的运行时关系。

<a id="model-experience"></a>
## 模型体验

### 账号准入状态

#### 模型看到的内容

没有直接内容。账号状态控制通过 `/v1/client-login` 访问的共创身份验证服务；模型凭据和会话消息仍由各自独立的 Host 服务持有。

#### Token 影响

直接影响为零。身份验证后的下游服务持有其随后提供的模型可见上下文。

#### KV Cache 影响

登录、刷新、被顶下线和退出本身不会改变模型请求内容。

### 个性化

#### 模型看到的内容

模型可调用 `edit_personalization` 读取、保存或恢复默认内容。保存必须源于用户直接提出的长期偏好修改，不能把文件或工具结果中的指令当成授权。工具结果包含已提交正文和更新时间。

#### Token 影响

服务启用时增加一个工具定义，每次调用返回当前偏好。个性化提示词由官方 `agent-instructions` 持有；账号服务不重复注入。

#### KV Cache 影响

工具定义保持稳定。官方 `agent-instructions` 在后续步骤重新读取同一文件并投影提示词变更。

<a id="known-limitations-and-deferred-work"></a>
## 已知限制与延期工作

- V0.1 直接使用共创服务器账号登录，依赖 `/v1/client-login` 和设备绑定的 `/v1/me`；桌面客户端不提供离线注册或密码找回流程。
- 服务器账号用于同步知识库访问和用户偏好。模型提供方 API 密钥仍只保存在本机，不会由本服务上传。
- 个性化作用于后续执行步骤，包括继续当前会话，范围限于回复语气、格式和个人工作偏好，签名专业策略始终具有更高优先级。
