# @gongchuang/signed-skill-runtime

[English](README.md) | 中文

## 概述

宿主持有的固定操作执行器，用于当前已签名共创技能包。它把操作清单版本绑定到桌面 Host 已经核验的准确技能版本，并依据该不可变文件清单校验每个被引用的技能文件；只接受清单封闭定义的参数，把文件路径限制在当前企业空间，净化子进程环境，并在无 Shell、无网络条件下调用固定隔离运行时。清单脚本使用内置且已核验的 Python 解释器。当该已签名检测器确认文档为 OLE Word 后，确定的企业空间文档读取操作可改用宿主持有的 Node 子进程提取文字；Electron 主进程不解析不可信文档。

<a id="behavior"></a>
## 行为

模型不能提交命令、脚本路径、解释器、环境变量、网址或任意参数向量。只有当前轮次已经由策略门禁确认激活所属技能，对应操作才会运行；普通文件读取不要求进入专业报告流程。

工具说明将 `parameterSchema` 与调用值分开，工作区文件参数按字符串展示。PTC 模式在 `run_code` 中先通过 `tools.skill` 加载所属技能，再用实际工作区路径执行操作。误传参数定义或 `{path: ...}` 对象时，在启动子进程前指出具体参数名。部分提取须保留可读文字并标明 OCR 页，不能重复执行已经成功的提取。

<a id="dev-note"></a>
## 开发备注

签名桌面 Host 提供已验证技能包清单、内置 Python 解释器与固定旧式 Word 适配器；本包不接受任意命令或环境运行时。

V1 的单个文件参数最多可声明 32 个互不重复的扩展名，使受签名 Office 导入清单能够纳入 `.dotm`、`.xltx` 与 `.xltm` 等模板格式。这只是允许清单容量，不代表格式已可解析；实际容器类型以及是否存在安全提取器仍由受签名检测器判定。

<a id="runtime-invariant"></a>
## 运行时不变式

不发布运行时不变式伴随入口，因为现有工具调用与工具结果记录已经覆盖每次操作及其有界 Host 结果。

<a id="model-experience"></a>
## 模型体验

### 受签名技能操作

#### 模型看到的内容

本包注册一个 `gongchuang_skill_operation` 工具。其说明把每个已验签操作的标识、所属技能、用途和全部必填参数的名称、类型、限制投射到原生 schema 与 PTC SDK。模型激活指定技能后，使用工作区路径调用操作，无需查找已安装的运行清单、脚本或解释器；可执行文件路径与环境变量值不公开。成功调用会返回操作和技能身份、通过或拒绝状态、受限 stdout 与 stderr、沙箱执行等级、脚本及技能包摘要和内置运行时完整性。声明 `stdout_json_schema_version` 的操作必须只输出一个 JSON 对象，且 `schema_version` 精确匹配；即使进程退出码为零，只输出警告、在 JSON 前追加警告、输出无效 JSON 或版本漂移也会被拒绝。操作未登记、技能未激活、文件变化、参数无效、路径越界、沙箱失败、超时、取消、退出码未登记或结构化 stdout 无效时，会返回工具错误，不会回退到命令运行器。

#### Token 影响

固定工具 schema 与已验签操作说明会增加请求前缀，其大小受清单中的操作数和参数数上限约束。只有模型实际调用操作时才会增加受限的结果 Token；本地摘要、路径、沙箱和进程校验不消耗模型 Token。

#### KV Cache 影响

已签名操作清单不变时，工具 schema 前缀保持稳定。当前技能包或操作清单更新会改变该前缀，并有意阻止复用变更位置之后的缓存。

<a id="known-limitations-and-deferred-work"></a>
## 已知限制与延期工作

- V0.1 只接受 `client-runtime-operations.json` 声明的操作。除确定的旧式 Word 文档读取适配器使用宿主持有的固定 Node/Electron 子进程外，其余清单脚本均使用 Python。原生辅助程序、软件包安装器、任意脚本和联网操作仍被排除。
- 旧式适配器读取 Word 97-2003 OLE 文档。`.wps` 后缀不被当作格式证明：OLE 容器必须成功暴露 Word 的 `WordDocument` 与选定的 `0Table` 或 `1Table` 流。专有或损坏的 WPS 二进制文件会返回需转换或拒绝结果，不猜测正文。
- 工作区限制依赖对应平台沙箱报告的执行等级。部分执行状态会原样进入操作回执，不能冒充完整隔离。
- 运行器只提供受限进程输出和确定性身份；每个所属技能及专业策略门禁仍负责判断业务拒绝结果能够修改后重试，还是必须停止交付。
