## 模块功能

### 新对话

围绕政策、项目和企业资料提问，上传文档、表格或图片，整理信息、核对数据、撰写材料。生成的文件可以直接打开，继续编辑和完善。

### 企业空间

按企业分别管理资料、项目对话和交付文件。新建企业目录，或连接已有资料文件夹，方便持续开展同一客户的多项工作。

### 技能中心

内置政策检索、项目匹配、高企申请书、专精特新评估、专利核稿、财务复核和材料一致性检查等专业技能。也可以浏览技能市场，安装需要的办公与业务能力。

### 知识库与扩展连接

连接知识库，检索政策、参考资料和业务知识；按需接入企业查询、文字识别及其他外部工具。需要知识库接入信息，可以添加下方微信联系。

### 自动化任务

设置定时或重复任务，处理政策跟踪、资料整理和周期性检查，并查看任务运行情况。

### 模型设置

自行选择模型服务，填写自己的模型连接信息；支持本地或自定义兼容端点。客户端无需注册产品账号，知识库可单独连接。
