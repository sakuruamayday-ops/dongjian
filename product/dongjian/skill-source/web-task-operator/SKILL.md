# 网页任务执行


## 客户端运行环境

本技能由客户端整包验签后加载，不执行其他宿主的独立安装、准备或二次验签流程。不得因客户端未携带独立安装清单而反复查找、安装或重试。

工具以本轮工具目录为准。若只开放 run_code，提供 description 与 code，在 code 内通过 await tools.skill、await tools.read、await tools.write、await tools.bash 等当前 SDK 绑定调用，不把 skill、read、write、edit、apply_patch 或 bash 当根工具。run_code 不是 Node.js：不可使用 require、process 或 fs；文件和进程操作使用 SDK 中的工具。读取文件固定调用 tools.read({ file_path: "..." })，不得把参数名写成 path。所有调用必须在 code 顶层实际 await，不得只定义未调用的包装函数。

run_code 只返回 null 或由字符串、数字、布尔值、数组和普通对象组成的纯 JSON；不得返回原始工具结果、Promise、undefined 或其他不可无损序列化的值。需要继续使用工具结果时在同一段 code 内完成处理，只返回后续决策必需的字段。

SDK 工具没有业务参数时也传入空对象 {}，不省略参数，不传 undefined。

用户限定读取指定文件或目录时，该范围优先于学习已有格式、复用历史案例和工作区探索。不读取其他会话成果或相邻项目来补齐答案，也不先扫描整个工作区。用户已经给出精确输入或输出路径时直接使用该路径；即使 SDK 提供 glob，也不得用 pwd、glob、find、ls 或目录枚举重新发现。来源未给出的字段保持未知；采集和写入时间由运行进程读取系统时钟，不复制示例日期。

技能说明中出现脚本名或命令，表示应按文档直接执行该命令，不表示可以先读取脚本源码。首次执行前不得读取 `scripts/**`、`examples/**`、`tests/**`、`*.example.*`、`package.json`，也不得列出技能目录来理解用法；只有文档给出的命令已经真实失败，且错误信息仍不足以确定调用契约时，才可定向读取与该失败直接相关的一个源码文件。此限制避免把生成任务退化为源码研读，也避免示例值污染用户事实。

技能文档已经给出连续的确定性命令时，在一个 run_code 中按依赖顺序连续执行相邻的输入校验、生成、导出和成品检查；除非前一步结果会改变下一步参数，不得每成功一条命令就返回模型重新规划。

客户端生成 PDF 时，统一使用宿主提供的 gongchuang_render_pdf：先按宿主要求对真实 HTML 源完成对话内预校验，再调用该工具。即使技能业务说明列有独立渲染脚本，也不得在客户端运行 render_pdf_stdout.js、直接启动 Chrome 或 Edge、查找或安装 Playwright 或 Chromium；这些独立渲染入口仅供未提供 gongchuang_render_pdf 的其他宿主。

调用可能持续运行的外部命令时，必须显式传入宿主支持的 timeoutMs，并保留真实退出状态。命令超时或失败后不得改成无超时后台运行，也不得用管道吞掉退出码。


先看本轮实际提供的浏览器、网页或MCP工具；可用时直接使用。能力报告只作为历史快照，报告缺失或未确认不否定当前工具。任务所需通道确实缺失时才进入对应配置或给出人工路径，不在每个网页任务重复配置。

使用当前宿主已经提供的浏览器或网页工具，不绑定特定平台、CLI、云服务或浏览器品牌。先读取 [execution-protocol.md](references/execution-protocol.md)，再执行任务。

登录后页面自动化受限，但用户仍能在浏览器中正常访问时，读取 [browser-local-replay.md](references/browser-local-replay.md)，引导用户在浏览器本地导出数据。

操作企策顾问并需要登录态检索、翻页或批量索引时，同时读取 [aiqice-browser-profile.md](references/aiqice-browser-profile.md)。

## 选择执行通道

按以下顺序选择能力：

1. 网站官方API、开放数据或专用连接器。
2. 宿主平台内置浏览器或已授权浏览器会话。
3. macOS、Windows或Linux本机已安装并经用户授权的浏览器。
4. 用户配置的标准浏览器自动化工具。
5. 只读网页获取工具。
6. 无可用通道时输出人工操作步骤，不虚构执行结果。

需要登录态时优先使用用户已经授权的会话。不得导出Cookie、密码、API Key或会话令牌，也不得将其写入Skill、日志和交付文件。

## 交互式登录

任务需要登录且当前没有有效会话时：

1. 打开目标网站的官方登录页面并将浏览器切换为用户可见；网站支持扫码时优先提示扫码登录。
2. 明确提示用户亲自扫码，或自行输入账号密码、验证码并完成二次验证。
3. 暂停自动操作，不读取输入内容、剪贴板、Cookie、验证码或会话令牌。
4. 用户确认“已登录”后，重新读取页面标题、URL和可见状态，验证是否进入目标系统。
5. 登录成功后恢复原任务；登录失败、账号无权限或页面异常时说明原因并停止。

不得代替用户输入密码、接收短信验证码、扫描二维码或保存登录凭据。除非用户明确要求保持页面，否则任务结束时关闭临时登录页面；是否保持登录状态由网站和宿主浏览器决定。

## 本机浏览器接管

宿主内置浏览器无法稳定读取重前端页面时，可降级使用用户电脑已安装的Safari、Chrome、Edge或其他受支持浏览器：

1. 检测浏览器是否已安装、是否运行以及是否能读取可访问性界面。
2. 新建独立标签页打开目标网站，不覆盖用户正在处理的页面。
3. 优先按可访问性元素定位地址栏、输入框、按钮、链接和列表；缺失时使用截图与坐标操作。
4. 每次点击、输入、滚动或导航后重新读取界面状态，不复用旧元素编号。
5. 需要登录时显示浏览器并由用户完成；成功后继续当前只读任务。
6. 任务结束时保留用户要求继续使用的页面，其余临时页面关闭。

本机浏览器操作适合登录、搜索、筛选、翻页和下载，但结构化批量采集仍应优先使用官方API或合法数据接口。不得读取浏览器历史、收藏、密码库或其他无关页面信息。

## 三级操作降级

所有网站统一使用以下三级路径，不为某一浏览器固化绝对坐标：

1. **可访问性定位**：优先按角色、名称、标签、当前值和稳定文本操作，并在动作后重新读取页面。
2. **截图定位**：可访问性树缺少可点击元素时，依据当前截图中的文字、相邻控件和布局执行单步操作；页面变化后坐标立即失效。
3. **人工接管**：登录、扫码、验证码、控件含义不明或连续两次定位失败时，将可见页面交给用户处理；确认完成后重新读取状态。

批量任务可在前两级之间逐页切换，但不得用历史截图、历史坐标或猜测继续运行。

## 登录态本地重放

扫码登录成功后，若宿主无法读取页面、浏览器自动化被当前URL限制或重前端页面无法稳定翻页，但用户本人仍能正常访问，可降级为浏览器本地重放：

1. 根据用户正在使用的浏览器输出对应的开发者工具操作提示。
2. 用户在目标网站同源页面中识别真实列表请求，只记录接口路径、方法、参数和响应结构。
3. 在该浏览器控制台内使用当前会话执行 `fetch`，由浏览器通过 `credentials: "include"` 自动携带登录态。
4. 结果在用户电脑本地导出为JSON、CSV或其他约定文件，再由Skill处理脱敏后的结果文件。

不得要求用户把完整cURL、Cookie、Authorization、CSRF令牌或其他认证Header发送到对话。不得通过本地重放绕过验证码、付费权限、访问控制、频率限制或网站明确禁止的自动化行为。

## 执行闭环

1. 明确目标网站、目标数据、允许操作、输出格式和停止条件。
2. 检查网站来源、当前登录状态、数据授权和调用限制。
3. 观察当前页面结构，记录页面标题、URL和关键控件。
4. 每次只执行一个可验证动作，再重新读取页面状态。
5. 对筛选、翻页、下载和提交结果进行数量或字段核验。
6. 保存必要的来源URL、查询条件、时间和失败页面，不复制无关个人数据。
7. 输出已完成事项、未完成事项、证据和需要人工处理的步骤。

## 确认门禁

执行以下动作前必须取得用户当次明确确认：

- 提交、发布、发送、删除或覆盖数据。
- 上传客户材料或包含个人信息的文件。
- 下单、付款、签署、授权或改变账号安全设置。
- 批量采集、长时间运行或可能产生费用的任务。
- 切换代理、地区、账号或创建新的浏览器身份。

历史确认不得自动延续到新的敏感动作。

## 失败与降级

- 遇到登录、扫码、验证码、二次验证或人工确认时显示官方页面并暂停，请用户在合法授权会话中完成。
- 遇到反自动化、访问限制或网站拒绝时停止，不尝试规避检测或绕过控制。
- 仅当用户已合法登录且页面允许正常访问、失败原因只是宿主无法操作页面时，才可提示浏览器本地重放；网站本身拒绝访问时不得使用该方案。
- 页面结构变化时重新观察，不沿用失效控件编号或坐标。
- 连续两次相同失败后切换合法通道或给出人工步骤。
- 只读任务可降级为网页读取；动态操作失败时不得声称已经执行。

## 输出要求

结构化提取必须说明字段、页面范围、筛选条件、采集时间、来源和缺失项。政策、企业、专利等高风险数据必须回到官方来源核验；第三方网站只作为索引或补充来源。
